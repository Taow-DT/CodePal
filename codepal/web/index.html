使用帮助

  • 新建文件：菜单「文件」→「新建文件」，输入文件名后创建并在编辑器打开。
  • 打开文件：菜单「文件」→「打开文件…」，或「转到」→「转到文件…」，在列表中点选；也可直接点左侧资源管理器中的文件。
  • 编辑与保存：在中间编辑器直接输入，Ctrl+S 保存。
  • 运行：菜单「运行」→「运行当前文件」（支持 .py/.js/.bat/.sh）；或在底部终端输入命令。
  • 查找：菜单「编辑」→「查找」，输入关键词跳转到下一处匹配。
  • AI 对话：右侧面板下达需求；首次使用请先在「设置」中配置 API Key。
